# EzEizo — דפי תקלות משותפים

גרסה: **1.9.0**

האפליקציות מתארחות ב־GitHub Pages: `/Metis/` למנהל ו־`/mechanic/` לטכנאי. Firebase Authentication משמש לכניסה ו־Cloud Firestore מסנכרן תקלות בזמן אמת. כל תקלה משויכת לטכנאי אחד לפי UID. רק הטכנאי המשויך רואה את התקלה. פתיחת תקלה מחייבת תיאור תקלה מהמנהל; סגירתה מחייבת גם תיאור תיקון, 12 הכרעות בפעולות (פעולה 11 מאפשרת ✓ או X), שעת סיום ומילוי מלא של טבלאות וחתימות בכל חלק שסומן. המנהל רואה את כל התקלות, יכול לשנות שיוך של תקלה פתוחה ולסנן תקלות סגורות לפי טכנאי. הטיוטה נשמרת במכשיר הטכנאי עד לסגירה בענן.

## השלמת הגדרה חד־פעמית ב־Firebase Console

1. Authentication → Users → Add user: צור את חשבון המנהל עם הדוא״ל `roisuissa6@gmail.com` וסיסמה שתבחר עכשיו (מומלץ להחליף סיסמה שנשלחה בצ'אט). אל תכניס סיסמה לקוד או ל־repo. אם החשבון כבר קיים, אין צורך ליצור אותו שוב.
2. Firestore Database → Rules: החלף את כל הכללים בתוכן הקובץ [`firestore.rules`](firestore.rules) ולחץ Publish. כניסה מוצלחת של החשבון הזה תיצור אוטומטית את מסמך ההרשאה `roles/{UID}` עם השם נימר. אין צורך להעתיק UID או ליצור מסמך מנהל ידנית.
3. אם הכניסה מדווחת על דומיין לא מורשה, Authentication → Settings → Authorized domains: הוסף `cartonush.github.io`.
4. פתח `/Metis/`, התחבר כמנהל ועבור לדף **ניהול משתמשים**. צור שני חשבונות טכנאי לדוגמה בלחיצה אחת. כתובות הדואר והסיסמאות האקראיות יוצגו פעם אחת; שמור אותן לפני רענון. אפשר גם ליצור טכנאי בשם ובכתובת שתבחר. טכנאים מתחברים ב־`/mechanic/`.
5. תקלה מקומית ישנה מהמכשיר שבו נוצרה תיובא אוטומטית אחרי כניסת המנהל כתקלה לא משויכת. עבור ל**תקלות פתוחות** ושייך אותה לטכנאי כדי שתופיע אצלו. אל תמחק את נתוני אפליקציית המנהל לפני הייבוא.

**השבתת משתמש:** כפתור "השבת גישה" מבטל את הרשאת הטכנאי ב־Firestore ושומר את ההיסטוריה והמספרים הסידוריים שלו. מחיקה מלאה של חשבון אחר מתוך Firebase Authentication דורשת Firebase Admin SDK בסביבה שרתית מאובטחת; GitHub Pages אינו יכול לבצע זאת. חשבון Auth מושבת עדיין קיים במסוף Firebase אך אינו מורשה לגשת לתקלות. ניתן למחוק אותו ידנית ב־Authentication → Users אם רוצים מחיקה מוחלטת. עצם יצירת חשבון Auth באמצעות ה־SDK היא ציבורית כשהספק Email/Password פעיל, אולם רק המנהל יכול ליצור עבורו מסמך הרשאת טכנאי ב־Firestore.

ה־web API key בקוד מזהה את פרויקט Firebase ואינו סיסמה. המערכת היא המחשה עם נתונים מומצאים. אין להזין מידע מסווג או פרטים מבצעיים.
