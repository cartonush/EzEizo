# EzEizo — הדגמת דף מנהל ודף טכנאי

גרסה: **1.2.0**

שתי אפליקציות PWA נפרדות בעברית:

- `/mechanic/` — דף הטכנאי: פרטי התקלה והקבועים לקריאה בלבד, תיאור תיקון, פעולות, טבלאות וחתימות למילוי.
- `/Metis/` — דף המנהל: עריכת פרטי האירוע, שמות הטכנאים, תיאור התקלה, ערכי הקבועים ונוסח הפעולות; יצירת קישור לדף טכנאי.

הכתובת הראשית `/` מפנה לדף הטכנאי. לכל דף manifest, אייקון ו-Service Worker משלו, כך שאפשר להוסיף כל כתובת בנפרד למסך הבית.

## הפעלה מקומית

```bash
python -m http.server 8000
```

פותחים `http://localhost:8000/mechanic/` ו־`http://localhost:8000/Metis/`. ב־GitHub Pages הנתיבים הם `https://cartonush.github.io/EzEizo/mechanic/` ו־`https://cartonush.github.io/EzEizo/Metis/`.

## איך עובדת ההמחשה

המנהל יכול לפתוח כמה תקלות, וכל אחת נשמרת ברשימת התקלות הפתוחות במכשיר שלו עם קישור נפרד. במכשיר שבו נפתח קישור הטכנאי, התקלה מתווספת לרשימה המקומית. הטכנאי בוחר תקלה, ממלא את דף העבודה, ולוחץ **שמירה וסגירה**. סגירה אפשרית רק כשכל הפעולות סומנו ונבחרה שעת סיום; אחריה הטופס נעול לעריכה. המנהל רואה תקלות שנסגרו באותו אחסון מקומי, או פותח קישור סגירה שהטכנאי שלח אליו כדי להוסיף אותן לרשימה במכשיר שלו. הקישור לסגירה כולל סיכום תיקון וכמויות שורות בטבלאות; חתימות ותוכן הטבלאות המלאים נשמרים בדף הטכנאי המקומי.

זו הדגמה סטטית ללא שרת, כניסה לחשבון, הרשאות או סנכרון בין מכשירים. שתי אפליקציות PWA באייפון עשויות להשתמש באחסון נפרד; לכן יש להעביר קישור פתיחה לטכנאי וקישור סגירה למנהל. פתיחה וסגירה של קישורים אינן מאומתות זהות; כל מי שמחזיק בקישור יכול לצפות בנתונים שבו ולשנות עותק מקומי. אין להזין נתונים שאינם מיועדים לחשיפה בדרך הזאת.
