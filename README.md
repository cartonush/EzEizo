# EzEizo — ניהול דפי תקלות (הדגמה מקומית)

גרסה: **1.5.1**

- `/Metis/` — המנהל פותח תקלות רבות. כל תקלה מקבלת מספר סידורי מקומי בן שש ספרות. המיקום מחולק לשדות טייסת ודת״ק. 12 הפעולות קבועות ולא ניתנות לעריכה. מוצגות שלושה דפים: פתיחת תקלה חדשה, תקלות פתוחות ותקלות סגורות. בדף הסגורות מוצגות כל התקלות ללא חיפוש.
- `/mechanic/` — רשימת תקלות פתוחות בלבד לבחירה. מספר התקלה מוצג בראש הטופס. סגירה מותרת רק לאחר סימון כל הפעולות ובחירת שעת סיום; לאחר מכן הדף ננעל לעריכה.

העברה בין שני אייקוני PWA באייפון מתבצעת מקומית באמצעות קובץ JSON: במנהל, בתקלות פתוחות, בוחרים ״העבר לטכנאי״ (גם בתקלות שנפתחו לפני עדכון זה); שומרים או משתפים את הקובץ. בטכנאי בוחרים ״קבל תקלה מהמנהל״ ופותחים את הקובץ. בסגירת דף, הטכנאי בוחר ״העבר דף סגור למנהל״, ובמנהל, בתקלות סגורות, בוחרים ״ייבוא דף סגור מהטכנאי״. אין סנכרון אוטומטי בין שתי אפליקציות PWA או בין מכשירים. הנתונים נשארים במכשירים ובקובץ ההעברה, והמספר הסידורי הוא מקומי.

אין כאן אימות זהות או הרשאות מנהל. קובץ ההעברה כולל את נתוני התקלה ללא הצפנה. לא להשתמש לצורך תיעוד מבצעי או להזין נתונים רגישים בהדגמה הזאת.

להרצה מקומית: `python -m http.server 8000`, ואז לפתוח `/Metis/` ו־`/mechanic/`.
