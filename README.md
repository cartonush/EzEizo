# דף טיפול בתקלה — PWA

גרסה: **1.0.1**

אפליקציית דף טיפול דיגיטלית בעברית ובכיוון RTL.

## הפעלה מקומית

יש להגיש את התיקייה דרך שרת HTTP מקומי (Service Worker לא פועל בפתיחת `index.html` כקובץ):

```bash
python -m http.server 8000
```

לאחר מכן פותחים `http://localhost:8000` בדפדפן. אפשר להתקין למסך הבית מדפדפן שתומך בהתקנת PWA. לאחר טעינה ראשונה, קובצי האפליקציה נשמרים לשימוש אופליין.

## מה כלול

- פרטי האירוע: מיקום 14/105, מטוס 603, קוד מערכת 74A, מערכת מכ״ם.
- תיאור התקלה נעול: פירוק והרכבה אנטנת מכם.
- תיאור תיקון לעריכה ושמירה מקומית.
- 12 פעולות עם סימון השלמה ומונה התקדמות.
- checkbox שפותח טבלאות יחידות שפורקו ויחידות שהורכבו עם שורה ריקה אחת בכל טבלה. כשמתחילים למלא שורה מתווספת שורה ריקה נוספת; אפשר לערוך ולמחוק שורות.
- הזום בדף מוגבל כדי למנוע הגדלה בטעות במכשיר נייד.
- Manifest, אייקון ו-Service Worker לשימוש כאפליקציית PWA.

הנתונים נשמרים ב-localStorage של הדפדפן במכשיר הנוכחי. אין עדיין שרת, סנכרון בין משתמשים או חיבור לדף מנהל.
