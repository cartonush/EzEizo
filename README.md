# EzEizo — ניהול דפי תקלות (הדגמה מקומית)

גרסה: **1.6.1**

- `/Metis/` — המנהל פותח תקלות רבות. כל תקלה מקבלת מספר סידורי מקומי בן שש ספרות. המיקום מחולק לשדות טייסת ודת״ק. 12 הפעולות קבועות ולא ניתנות לעריכה. מוצגות שלושה דפים: פתיחת תקלה חדשה, תקלות פתוחות ותקלות סגורות. בדף הסגורות מוצגות כל התקלות ללא חיפוש.
- `/mechanic/` — רשימת תקלות פתוחות בלבד לבחירה. מספר התקלה מוצג בראש הטופס. סגירה מותרת רק לאחר סימון כל הפעולות ובחירת שעת סיום; לאחר מכן הדף ננעל לעריכה.

העברה בין שני אייקוני PWA באייפון מתבצעת מקומית: במנהל, בתקלות פתוחות, בוחרים ״העתק לטכנאי״; בטכנאי בוחרים ״קבל תקלה מהלוח״. בסיום העבודה מעתיקים את הדף הסגור בטכנאי וקולטים אותו במנהל. אם גישת הלוח אינה זמינה, אפשר לשתף ולייבא קובץ JSON דרך הכפתורים הסמוכים. גם תקלות שנפתחו בגרסאות קודמות נשארות אצל המנהל וניתנות להעברה. אין צורך בהרשאת GitHub ואין סנכרון אוטומטי בין אפליקציות מותקנות בנפרד.

אין כאן אימות זהות או הרשאות מנהל. נתוני ההעברה בלוח או בקובץ אינם מוצפנים. לא להשתמש לצורך תיעוד מבצעי או להזין נתונים רגישים בהדגמה הזאת. הקובץ `data/issues.json` שנוצר בגרסה 1.6.0 נשאר ב־repo ללא שימוש; אין אפשרות לכתוב אליו אוטומטית מתוך שני דפי GitHub Pages ללא הרשאה או שירות כתיבה.

להרצה מקומית: `python -m http.server 8000`, ואז לפתוח `/Metis/` ו־`/mechanic/`.
