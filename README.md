# EzEizo — הדגמת דף מנהל ודף טכנאי

גרסה: **1.1.0**

שתי אפליקציות PWA נפרדות בעברית:

- `/mechanic/` — דף הטכנאי: פרטי התקלה והקבועים לקריאה בלבד, תיאור תיקון, פעולות, טבלאות וחתימות למילוי.
- `/Metis/` — דף המנהל: עריכת פרטי האירוע, שמות הטכנאים, תיאור התקלה, ערכי הקבועים ונוסח הפעולות; יצירת קישור לדף טכנאי.

הכתובת הראשית `/` מפנה לדף הטכנאי. לכל דף manifest, אייקון ו-Service Worker משלו, כך שאפשר להוסיף כל כתובת בנפרד למסך הבית.

## הפעלה מקומית

```bash
python -m http.server 8000
```

פותחים `http://localhost:8000/mechanic/` ו־`http://localhost:8000/Metis/`. ב־GitHub Pages הנתיבים הם `https://cartonush.github.io/EzEizo/mechanic/` ו־`https://cartonush.github.io/EzEizo/Metis/`.

## איך עובדת ההמחשה

המנהל ממלא טופס ויוצר קישור. הקישור מכיל את פרטי התקלה ומציג אותם בדף הטכנאי בלי שרת. שינוי בטופס המנהל לאחר יצירת הקישור אינו משנה קישור קודם; צריך ליצור קישור חדש. דף הטכנאי שומר את התיקון, הסימונים והחתימות ב־localStorage של המכשיר, בנפרד לכל קישור שנוצר. טיוטת המנהל נשמרת מקומית במכשיר שלו.

זו הדגמה ללא כניסה לחשבון, הרשאות או סנכרון. כל מי שמחזיק בקישור יכול לראות את פרטי התקלה שבו. אין להזין נתונים שאינם מיועדים לחשיפה בדרך הזאת.
