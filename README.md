# EzEizo — ניהול דפי תקלות (הדגמה מקומית)

גרסה: **1.3.0**

- `/Metis/` — המנהל פותח תקלות רבות. כל תקלה מקבלת מספר סידורי מקומי בן שש ספרות. מוצגות רשימות פתוחות וסגורות וחיפוש סגורות לפי מספר תקלה.
- `/mechanic/` — רשימת תקלות לבחירה. מספר התקלה מוצג בראש הטופס. סגירה מותרת רק לאחר סימון כל הפעולות ובחירת שעת סיום; לאחר מכן הדף ננעל לעריכה.

אין עוד העברת קישורים בדפי האפליקציה. שני הדפים משתמשים כרגע ב־localStorage של אותו הקשר דפדפן. לכן ההדגמה עובדת בין שתי לשוניות באותו דפדפן, אבל **אין סנכרון בין מכשירים או בהכרח בין שתי אפליקציות PWA שמותקנות בנפרד ב־iPhone**. המספר הסידורי המקומי אינו מבטיח ייחודיות כללית עד שיחובר מסד נתונים מרכזי. נתונים קיימים מהגרסה הקודמת שנוצרו בקישור עשויים להישאר במכשיר שבו הקישור נפתח.

אין כאן אימות זהות או הרשאות מנהל. לא להשתמש לצורך תיעוד מבצעי או להזין נתונים שאינם מיועדים לחשיפה ציבורית לפני חיבור אחסון מאובטח והרשאות.

להרצה מקומית: `python -m http.server 8000`, ואז לפתוח `/Metis/` ו־`/mechanic/`.
